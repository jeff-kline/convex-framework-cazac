# Open problems

This file has been retired as an independent document. The open-problems
list it used to restate (with more attack-plan detail than the paper's
own condensed version) now lives only in `../main.tex`'s **"Open
problems"** section (§7; build with `pdflatex main.tex`, or read
`../main.pdf`), labeled there Q1-Q7:

- Q1 — single-point convergence (settled).
- Q2 — full fixed-point census.
- Q3 — why $N=2$ empirically outperforms $N=1$.
- Q4 — rate of convergence near $\mathrm{CAZ}(n,N)$ (essentially settled
  locally; one remaining gap at non-Zadoff-Chu points).
- Q5 — what the $\tau$-continuation presolve actually buys.
- Q6 — the central open question: probabilistic convergence to CAZAC.
- Q7 — the elliptope's rank-1-convergence conjecture (pointwise half
  settled by direct citation to Felzenszwalb-Klivans-Paul's Theorem 20;
  residual measure-zero refinement open).

Keeping a fuller, independently-worded version of this list here as well
as in `main.tex` meant the two could name a different number of open
problems, a different attack plan, or a different citation for the same
claim — and did, more than once. `main.tex` is now the single source of
truth; this file exists only so old links into `problems/` don't 404.
