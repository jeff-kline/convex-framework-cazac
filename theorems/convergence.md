# Convergence of iterated SOCP refinement for CAZAC feasibility

This file has been retired as an independent markdown mirror of the
paper. The theorems, proofs, and discussion it used to restate now live
only in `../main.tex` (build with `pdflatex main.tex`, or read
`../main.pdf`):

- Setup and notation — §1.
- The iteration as a generalized power method (Props. 1-4) — §2.
- Theorem A (global convergence) and the elliptope corollary — §3.
- Theorem B (obstruction) — §4.
- Theorem C (finite exact termination) — §5.
- Theorem D and regularity (R), including the Zadoff-Chu/Björck material — §6.
- Open problems (Q1-Q7) — §7.
- Verification status and provenance — §8.

Keeping a full second copy of this content in markdown, alongside the
LaTeX original, meant every revision had to land correctly in two places
— and across several audit rounds, it didn't, repeatedly. `main.tex` is
now the single source of truth; this file exists only so old links into
`theorems/` don't 404.
